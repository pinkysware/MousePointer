# 鼠标指示 (Mouse Pointer)

一个 Windows 上的白手套鼠标指针定位工具：按下全局热键，在鼠标指针位置弹出一只米老鼠风格的白手套，食指精确指向指针；移动鼠标或再按一次热键即可隐藏。

平时屏幕上没有任何覆盖层，不影响正常操作。

## 功能

- 🖱️ **一键定位**：按下热键（默认 `F10`），在鼠标位置弹出白手套
- 🧤 **指向精准**：食指指尖自动对齐指针位置（通过像素级指尖检测）
- ⚙️ **可配置热键**：面板内直接按一个键即可替换热键，支持字母、数字、F1-F12、方向键、标点键、编辑区键、小键盘运算键
- 🔄 **开机启动**：可勾选随系统启动
- 📌 **系统托盘**：最小化到托盘，右键菜单可显示主界面或退出
- 🌐 **双语**：根据系统语言自动切换中英文界面

## 使用

### 方式一：直接运行 exe（推荐）

从 [Releases](../../releases) 下载 `MousePointer.exe`，双击运行即可。无需安装 Python。

首次运行时会在 exe 同目录生成 `hotkeys.json`（配置）和 `mouse_highlight.log`（日志）。

### 方式二：源码运行

依赖：Python 3.10+，以及 `Pillow`、`pywin32`、`numpy`。

```bash
pip install pillow pywin32 numpy
python mouse_highlight.py
```

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 按热键（默认 `F10`） | 显示 / 隐藏白手套 |
| 移动鼠标 | 自动隐藏手套 |
| 点击热键输入框后按一个键 | 更换热键 |
| 点击「保存」 | 保存配置并立即生效 |
| 标题栏 `—` | 最小化到系统托盘 |
| 标题栏 `✕` | 退出程序 |

## 技术要点

- **GDI 分层窗口**：手套窗口使用 Win32 `WS_EX_LAYERED` + `UpdateLayeredWindow`，直接合成 PNG 的 per-pixel alpha，绕过 Tk 渲染管线，避免「透明色被合成成紫色」的问题
- **像素级指尖检测**：用 numpy 分析手套图的 alpha 通道，自动定位食指尖端像素位置
- **线程安全的热键切换**：全局热键的注册/注销在同一线程内完成，主线程只写共享变量，避免 `WM_HOTKEY` 投递线程错乱
- **托盘与 Tk 的无重入方案**：WndProc 回调只写一个共享标志位，由主线程轮询执行，彻底规避 Tcl 重入崩溃
